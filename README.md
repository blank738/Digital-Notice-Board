Digital Notice Board – Project Description

Digital Notice Board is a web-based application developed using PHP and MySQL to provide an easy and digital way for colleges to share important announcements and notices with students.

The admin can securely log in and add, edit, delete, and upload notice images. Students can create an account, log in, and view the latest college notices, announcements, and uploaded images. Students can also view the notice image in full size and download it for future reference.

The system uses role-based login and PHP sessions to ensure that only administrators can manage notices, while students have view-only access. This reduces the need for physical notice boards and makes important information available to students quickly and conveniently.

Technologies Used
Frontend: HTML, CSS
Backend: PHP
Database: MySQL
Server: WampServer / Apache
Security: PHP Sessions & Password Hashing
